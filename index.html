Fast Processing
Full mastering chain + WAV I/O for 3.4 min stereo @ 44.1kHz in 0.17 seconds.
~20× realtime
FFT Toolkit
Radix-2 Cooley-Tukey with Hann, Hamming, Blackman-Harris windows. Dominant frequency detection.
Cooley-Tukey
Dynamics Processing
Compressor with soft-knee quadratic gain. Brickwall limiter with sliding max-hold lookahead + stereo linking.
stereo-linked
Streaming I/O
Block-by-block WAV read/write. Never loads entire file into RAM. PCM 16/24/32-bit float with TPDF dither.
zero-allocation
